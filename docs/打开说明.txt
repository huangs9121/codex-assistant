Codex Quota（趁手）安装与使用说明

适用版本：1.5.2（构建 27），2026-10-10 正式发布。
本版新增灵动岛显示器选择，修复收起后透明区域悬停误触。
安装名称和更新路径继续使用 Codex Quota，应用内名称为“趁手”。

一、适用电脑
Apple Silicon 芯片的 Mac（M 系列），macOS 13 或更新版本。
不支持 Intel Mac、Windows 或 Android。
Codex 实时额度需要本机已安装并登录 Codex；Claude 实时额度需要已安装并登录官方 Claude Code CLI。
本工具不附带账号或登录信息。

二、安装并打开
1. 从项目 GitHub Release 下载 Codex.Quota-arm64.zip，解压得到 Codex Quota.app。
   下载：https://github.com/huangs9121/codex-assistant/releases/tag/v1.5.2
   更新 ZIP 只包含应用，本说明单独提供。
2. 如果旧版正在运行，先退出旧版。
3. 将 Codex Quota.app 拖入 Finder 的“应用程序”文件夹；已有旧版时选择替换。
4. 在“应用程序”中双击 Codex Quota，按引导选择习惯和需要的功能；引导可跳过。
5. 点击菜单栏额度图标，或悬停/点击屏幕顶部灵动岛，打开面板。
   这是常驻工具，没有普通主窗口、Dock 图标是正常现象。

三、首次打开被 macOS 拦截
本包使用本地自签名，未经 Apple 公证。确认文件来自上述项目后：
1. 先双击应用尝试打开一次。
2. 打开“系统设置 → 隐私与安全性”，向下滚动。
3. 找到 Codex Quota 的拦截提示，点击“仍要打开”，按系统要求确认后点击“打开”。
之后通常可以直接双击启动。不需要关闭系统整体安全保护。
若提示文件损坏，先重新下载并解压；若系统明确报告恶意软件，不要强行放行。
Apple 官方说明：https://support.apple.com/zh-cn/102445

四、显示入口、额度和更新
• 点击面板齿轮，或在应用内按 ⌘,，打开同一个设置中心。
• “设置 → 通用 → 显示入口”可选菜单栏或灵动岛；灵动岛可选单个/双持及左右方位。
• 选择灵动岛后，同页“灵动岛显示器”可选自动、内置显示器或外接屏，立即生效并保存。目标断开时暂回可用屏，保留原选择；重连后恢复。菜单栏模式不显示此项。
• 鼠标悬停在可见的黑色岛上才会展开，下方透明区、肩部和圆角外不触发；展开后可按 Esc 收起，再移回岛继续使用。
• Codex 实时额度每 15 秒刷新；短暂失败保留上次数据 3 分钟，持续失败后显示原因并尝试本地记录。
• Claude 通过官方 CLI 读取：选中 Claude 或双持灵动岛显示 Claude 时每 5 分钟刷新，其余每 15 分钟；手动刷新立即执行。
• “设置 → 额度 → 显示 Codex 重置预告”默认关闭，仅控制面板可见性，不影响个人倒计时、后台同步和通知。
• “设置 → 关于 → 检查更新”可手动检查；确认更新后自动下载、校验、替换并重启。
• “设置 → 关于 → 查看引导”可重新打开首次使用说明。

五、工具与按需授权
新安装预置 7 条右键手势，总开关默认关闭；从“设置 → 右键手势”按需开启。
已有用户的开关和规则保留；默认排除 Blender，用户移除后不自动补回。
仅查看额度不必提前授予所有权限。
使用滚轮反转或右键手势时，按提示授予“辅助功能”。
使用按键映射时，另需“输入监听”。恢复终端会话可能请求控制 Terminal 的“自动化”权限。
希望收到提醒时允许通知；具体手势、按键和输入法效果需要在目标软件中实际试用。
“设置 → 防睡眠 → 保持 Mac 运行”是手动合盖防睡眠，首次需要管理员授权；保持到手动关闭或退出，重启默认关闭，合盖使用时保持通风。
同页“开始熄屏”在有运行任务时建立临时保护，全部任务结束后释放；亮屏不主动释放。
熄屏任务保护不修改长期电源设置，使用时插电且不要合盖；它与手动合盖防睡眠是两个功能。

六、常见情况
• 打开后没看到：检查顶部菜单栏或灵动岛；菜单栏图标可能被刘海或其它图标遮挡。
• 没有额度：确认所选服务已登录、网络正常，再手动刷新并查看来源或失败提示。
• 想开机启动：先安装到“应用程序”，再从“设置 → 通用 → 登录时启动”开启，默认关闭。
• 12 小时能耗仍高：活动监视器统计会包含更新前的运行时段；应观察新版本完整使用周期，不能用一次短时低读数推算续航。

验证范围
已通过 311 项核心测试，含显示器选择和轮廓命中回归；内屏已实测透明区不误触、可见岛悬停展开、正文按 Esc 后再次悬停正常，以及断屏后的内屏回退。
发版时另检查签名、应用压缩包和上一正式版客户端的公开自动更新链路。
外屏实体重连与悬停、菜单追踪离开、全屏/缩放/减少动态效果仍待实测。公开更新包验证不等于另一台 Mac 已完成更新；Mac mini 实机更新和完整 12 小时能耗仍待验收。
