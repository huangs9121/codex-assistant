# Codex Quota v1.3.0 推广计划

> 产品：Codex Quota — 免费开源的 macOS 菜单栏 Codex 额度监控 + 效率工具
> 仓库：https://github.com/huangs9121/codex-assistant
> 本版亮点：右键手势触发快捷键（系统级鼠标手势）+ 便捷工具统一窗口 + 按应用生效的过滤

## 一、卖点排序（按传播力）

1. **右键手势触发快捷键**（本版最大差异化）：按住右键画个方向就触发快捷键，双段 8 方向组合，⚡️立即触发，还能限定只在某App里生效——「浏览器鼠标手势」的系统全局版。视觉演示效果极强，是短视频/动图的天然素材。
2. **菜单栏额度监控**（基本盘）：Codex 剩余额度、重置倒计时常驻菜单栏，重置预告推送。
3. **便捷工具统一窗口**（易用性）：滚轮反转 + 全局快捷键呼出 + 右键手势，三件套一个窗口管完。
4. **免费开源 + 隐私克制**：不读对话、不存 token，只从本机取数据——每个平台正文都要带这句。
