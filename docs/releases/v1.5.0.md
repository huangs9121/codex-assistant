# Codex Quota 1.5.0 更新公告

本次更新新增 Claude 额度与任务，提供灵动岛和菜单栏两种入口，并换上「趁手」新图标。

- **新增 Claude 额度**
  在额度区切换 Codex / Claude，查看 Claude 的 5 小时与本周剩余额度及重置时间。数据通过本机的官方 Claude Code 读取，不访问钥匙串，不会弹出授权框；读取不到时，回退显示 Claude 桌面版记录的百分比。
- **新增 Claude 任务**
  选中 Claude 时，任务区列出 Claude 桌面会话和终端里运行的 Claude Code。点击即可在 Claude 中打开对应会话，或回到原终端。
- **新增灵动岛显示方式**
  可在设置中把入口切换为灵动岛。灵动岛面板用双圈显示额度：外圈本周、内圈 5 小时，右侧是完整任务列表。菜单栏保留原来的紧凑面板，并在顶部加上 Codex / Claude 切换。
- **首次使用引导与统一设置**
  新用户可按四步完成鼠标滚轮、右键手势和按键映射等常用设置，也可以跳过。所有设置集中到一个窗口，应用内按 ⌘, 即可打开。
- **重置时间更清楚**
  鼠标停在倒计时旁的图标上，可查看完整的重置日期和时区。来源没有提供重置时间时，会明确显示“尚未获取重置时间”。
- **其他改进**
  清理已完成项时可勾选“不再提醒”。适配新版 ChatGPT 应用中 Codex 的位置，恢复 Codex 实时额度和会话恢复。应用图标更新为「趁手」。
