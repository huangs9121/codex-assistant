# Codex Quota 1.5.1 更新公告

本次更新降低后台占用，加入 Codex / Claude 双持灵动岛，并改进布局、动画和读取失败提示。

- **降低后台占用**
  会话日志改为增量读取，实时额度读取成功时跳过备用日志；数据没有变化时，不再重复刷新界面。压缩日志尾部缓存，避免少量缓存持有整块大日志。额度刷新频率与任务保护触发条件保持不变。
  本机各 330 秒的对照采样中，应用及其子进程平均 CPU 从 5.45% 降至 1.45%。这是短时 CPU 测量，不代表电池续航提升比例；完整 12 小时能耗趋势仍待观察。
- **新增双持灵动岛**
  刘海两侧可同时显示 Codex 与 Claude 的标志和剩余额度。有 5 小时额度时优先显示，否则显示本周额度。点击或悬停哪一侧，就展开对应服务；可在设置中选择单个或双持、调整左右位置，也可右键左右互换。
- **布局更紧凑，动画更顺畅**
  展开面板收窄至 600pt，高度随内容调整，任务列表最多显示 6 行，更多任务可滚动查看。收起高度与菜单栏一致，内容避开刘海。改进贴顶展开动画，修复点桌面后收起时闪烁的问题。
- **读取失败提示更清楚**
  Codex 短暂读取失败时保留上次成功读数，连续失败超过 3 分钟后再提示；悬停可查看原因。无法连接 ChatGPT 服务器时，显示对应的网络说明。
- **更新包兼容修复**
  打包时排除 macOS 扩展元数据，并检查压缩包只包含应用，避免额外文件混入自动更新包。保留原有签名、完整性和应用身份校验。
