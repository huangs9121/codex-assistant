# Codex Quota v1.2.1

新增鼠标滚轮反转与全局快捷键呼出 Codex，调度任务面板全面升级：

- 鼠标滚轮垂直反转：仅作用于鼠标滚轮，触控板方向不受影响；对齐 Scroll Reverser 成熟实现，可与系统「自然滚动」共存。
- 全局快捷键呼出 Codex：双击修饰键（支持区分左右 ⌘/⌥/⇧/⌃，体验对齐 Kimi 客户端）映射为 Codex「窗口弹出快捷键」，触发手势与目标快捷键均可在设置中录制自定义。
- 统一「全局快捷键设置」窗口：所有快捷键配置集中一处，界面内附 Codex 侧的设置指引。
- 调度任务面板增强：支持多任务目录扫描；新增「清理完成任务」一键清空已完成任务；任务行新增「继续」「删除」按钮处理历史遗留任务；设置菜单合并为一行重排版。
- 重置倒计时更人性化：不足 24 小时显示小时数，天数向上取整。
- 修复 Tibo 重置信号本地兜底识别过严、可能漏报的问题。
- 修复历史遗留任务（孤儿会话条目）点删除无反应的问题。
- 改用稳定自签名证书，重装/升级不再丢失辅助功能与输入监听权限。

## 安装说明

`v1.1.5` 起支持应用内自动更新：打开菜单面板 → 齿轮 → 检查更新即可升级。也可以从 GitHub 下载 `Codex Quota-arm64.zip` 手动覆盖旧版。

当前发布使用本地自签名证书且未经 Apple 公证。首次打开如果被 macOS 拦截，请先尝试打开一次，再进入“系统设置 → 隐私与安全性”点击“仍要打开”。请只从本仓库下载。
