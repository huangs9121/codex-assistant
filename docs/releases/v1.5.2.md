# Codex Quota 1.5.2 更新公告

本次更新加入灵动岛显示器选择，并修复收起后鼠标移入下方透明区域就展开的问题。

- **选择灵动岛所在显示器**
  在“设置 → 通用”选择灵动岛后，可选择自动、内置显示器或外接屏，立即生效并保存。自动模式继续优先使用刘海屏；指定屏幕断开时暂回可用屏，保留原选择并显示未连接提示，重连后恢复。切换屏幕时取消旧的悬停和动画状态。
- **修复透明区域悬停误触**
  悬停范围与可见岛的轮廓一致，下方透明区、肩部及圆角外不触发展开。保留原有展开和收起延时，延时执行前再次核对鼠标位置；收起和菜单结束后同步悬停状态，修复正文按 Esc 后移回岛无法再次展开的边界情况。

验证：311 项核心测试通过，包含新增 7 项显示器选择与 5 项轮廓命中回归。内屏已实测透明区不误触、可见岛悬停展开、正文按 Esc 后再次悬停正常，以及断屏后的内屏回退和未连接提示。

外屏实体重连与悬停、菜单追踪离开、全屏/缩放/减少动态效果仍待实测。更新 ZIP 继续只包含应用，安装与使用说明单独提供。
