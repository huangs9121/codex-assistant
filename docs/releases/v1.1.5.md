# Codex Quota v1.1.5

本版本集中修复重置提醒和 Tibo 预告识别问题，并加入应用内自动更新：

- 新增应用内自动更新：发现新版后可直接下载、校验、替换并重启；安装失败会保留旧版本并提供 GitHub 下载入口。
- 下载更新时校验 GitHub SHA-256、固定资产路径、Bundle ID、目标版本、代码签名和 arm64 架构。
- 修复同一次额度重置因服务端周期时间小幅修正而反复发送系统通知的问题；提醒状态会跨应用重启保存。
- 额度开始被使用后才重新开启下一次重置提醒，额度保持 100% 时不会重复通知。
- Tibo 原帖明确提到 `limit reset` 且包含未来时间或意图表达时，即使上游分类缺失或标记为模糊提示，也能识别为重置预告。
- 支持把 “in a few hours” 解析为约 3 小时后的预期时间，并继续提供原始 X 帖子跳转。
- 将“按住 Command 可自由拖动位置”提示移动到菜单最顶部。

## 安装说明

`v1.1.4` 尚未包含自动更新器，因此本次需要从 GitHub 手动下载 `Codex.Quota-arm64.zip` 并覆盖旧版。安装 `v1.1.5` 后，后续版本可以在 App 内完成更新。

当前发布仍使用 ad-hoc 签名且未经 Apple 公证。首次打开如果被 macOS 拦截，请先尝试打开一次，再进入“系统设置 → 隐私与安全性”点击“仍要打开”。请只从本仓库下载。
