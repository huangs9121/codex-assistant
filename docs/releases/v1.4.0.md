# Codex Quota v1.4.0

这次更新把任务、会话和终端的状态集中到菜单栏面板，并修复了便捷工具窗口和完成任务清理的问题。

- **会话总览**：Codex 会话按父子关系分组，默认折叠，并显示桌面端或 CLI 创建来源。桌面端与 CLI 的共享历史合并展示；可打开对应 Codex 聊天，子 Agent 会话则打开所属父任务。
- **清除完成会话**：橡皮擦按钮提示“清除完成任务”，一次隐藏所有明确已完成的历史会话，不再局限于当前显示的 8 组；刷新期间点击也会排队执行。不删除会话文件，重新活跃后自动恢复显示；运行中和状态未知的会话会保留。
- **当前 CLI 进程**：单独显示正在运行且关联会话的 CLI 进程，可定位所属终端，避免对同一会话重复恢复。
- **面板与便捷工具**：状态面板底部新增便捷工具入口；便捷工具窗口支持缩放和最小化，修复切换到其他应用后窗口消失、⌘W 关闭及 ⌘M 最小化失效的问题。打开状态面板时不再默认把焦点落在设置按钮上。
- **手动合盖不睡眠**：开关移到状态面板底部、便捷工具图标右侧。关闭显示灰色月亮，开启显示橙色实心太阳；切换中显示进度，失败显示警告。手动开启后持续保持，手动关闭或退出应用后恢复，重启默认关闭。自动任务判断已停用，任务异常结束、等待审批或历史记录不会再触发续期。首次启用需要 macOS 管理员授权，并会接管系统全局防睡眠设置；合盖运行请保持通风。
- **任务检测改进**：跨日期会话和长输出日志不再因扫描范围或日志截断而被漏判为未知状态。

## 安装说明

`v1.1.5` 起支持应用内自动更新：打开菜单面板 → 齿轮 → 检查更新即可升级。也可以从 GitHub 下载 `Codex Quota-arm64.zip` 手动覆盖旧版。

定位或恢复终端任务时，macOS 可能请求控制 Terminal 的「自动化」权限。

当前发布使用本地自签名证书且未经 Apple 公证。首次打开如果被 macOS 拦截，请先尝试打开一次，再进入“系统设置 → 隐私与安全性”点击“仍要打开”。请只从本仓库下载。

## 验证边界

手动模式不依赖任务状态；关闭和退出会撤销保护，异常退出由现有最长60秒租约机制回收。

249 项核心测试通过。真实系统已验证手动开启、持续续期、手动关闭与退出恢复；面板以同场景内容验证关闭、开启、处理中和错误四种图标。物理合盖运行尚未实测，不能以系统电源设置读回代替设备验收。
