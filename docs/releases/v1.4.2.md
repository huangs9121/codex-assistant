# Codex Quota v1.4.2

本次更新增加节点评分和熄屏继续工作，并改善会话跳转与日常操作。

- **会话整行跳转**：点击标题、副标题或行内空白即可打开会话；左侧子任务展开按钮独立控制折叠，子任务跳转所属聊天。
- **VPN 节点评分**：支持 Codex、CC、下载、开发依赖、视频和 IP 信誉六项检测，提供进度、取消、详情、历史记录及排行榜排序。缺项不补零，旧口径记录单独标识；删除节点前确认并保存恢复备份。首次安装从空列表开始，不附带个人测量数据。
- **熄屏继续工作**：底部工具栏新增入口，熄屏期间临时防止空闲休眠，亮屏或退出后释放。建议插电使用且勿合盖，此功能不替代合盖保护。
- **统一按钮提示**：悬停约 0.5 秒显示，移出或操作后收起，减少重复提示。
- **重置倒计时**：菜单栏与面板统一向下取整；满一天显示天和小时，不足一天显示小时和分钟，不足一小时显示分钟。
- **工具窗口快捷键**：支持全选、复制、粘贴和剪切。

## 安装与更新

已有用户可通过应用菜单中的「检查更新」升级，也可下载 `Codex.Quota-arm64.zip`，解压后覆盖 `/Applications/Codex Quota.app`。

适用于 Apple Silicon、macOS 13 及以上。沿用本地自签名证书，未经 Apple 公证。用户设置和本机测量记录保留。

## 验证范围

270 项项目回归通过。构建流程检查应用元数据、架构、签名与 ZIP 完整性；发布后另行验证上一公开版本的自动更新发现、下载与 SHA-256 一致性。

会话整行点击及物理熄屏仍待现场验收，自动化界面读取超时。电源控制器的断言创建与释放已通过受控验证，不等同于物理屏幕验收。节点评分中的 API 可达性不代表真实推理成功，视频档位不代表最高可用清晰度，IP 信誉分不是账号安全保证。
