# Codex Quota 1.5.3 更新公告

本次更新补强菜单栏面板的外部点击收起行为，统一设置界面，并修复倒计时日期截断和节点评分窗口过小的问题。

- **补强菜单栏面板收起行为**
  在原生自动收起机制之外，增加外部鼠标点击监听。点击面板外部时关闭面板，保留内部操作和菜单栏图标再次点击关闭；面板收起后移除监听。
- **统一原生设置界面**
  八个设置页使用原生侧栏、系统字体和语义色，统一分组间距、表格和按钮。侧栏可收起并再次展开，页面选择在重启后保留；修正规则表格的列宽和滚动空间，约束设置窗口的最小尺寸。
- **完整显示倒计时与重置日期**
  缩短灵动岛重置行的文案，保留双单位倒计时和精确日期，避免窄列挤掉日期末尾。
- **修复节点评分窗口下限**
  给内容添加 1000×700 的最小尺寸约束，避免窗口继续缩小后挤掉历史排行与操作区。

验证：311 项核心测试通过；本机已确认点击面板外部会收起、再次点击菜单栏图标会关闭并保持关闭。设置页、侧栏和窗口尺寸已有实际界面验收。

用户原设备此前未复现报告中的问题；报告机器 macOS 26.6.2 尚未独立复现或实体验证，外部右键、控制中心等特殊交互未另验。本次是兼容性补强，不宣称已验证这些环境。

更新 ZIP 只包含 Codex Quota.app；安装与使用说明单独提供。
