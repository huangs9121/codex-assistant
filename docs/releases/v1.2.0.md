# Codex Quota v1.2.0

菜单一览界面全新改版，新增调度任务跟踪与一键回到现场：

- 全新面板界面：点击菜单栏图标改为弹出状态面板，配额大数字与进度条置顶，取代原纯文字菜单。
- 配额双窗口：5 小时窗口与每周窗口同屏显示，一眼看清哪个先耗尽；无数据的窗口自动隐藏。
- 调度任务跟踪：面板直接显示派给 Codex 的任务，含任务名、运行中脉冲动画、运行时长、耗时或退出码。
- 一键回到现场：单击任务按钮直接在终端恢复该任务的 Codex 会话并继续追问；Option+单击改为仅复制恢复命令。
- 重置预告常显：Tibo 重置预告固定显示在配额区下方，无信号时保留占位；已预告时显示实时倒计时，点击查看 X 原帖；预告状态升级时再次推送通知。
- 设置收纳：显示样式、标识样式、开机启动、检查更新等收进面板左下角齿轮菜单；右键点击菜单栏图标可直接打开设置。
- 修复任务列表混入进度查询痕迹、后台任务全部显示同名无法区分的问题。
- 修复同一版本在启动台出现两个图标的问题。

## 安装说明

`v1.1.5` 起支持应用内自动更新：打开菜单面板 → 齿轮 → 检查更新即可升级。也可以从 GitHub 下载 `Codex Quota-arm64.zip` 手动覆盖旧版。

当前发布仍使用 ad-hoc 签名且未经 Apple 公证。首次打开如果被 macOS 拦截，请先尝试打开一次，再进入“系统设置 → 隐私与安全性”点击“仍要打开”。请只从本仓库下载。
