# Codex Quota v1.4.1

这次更新完善便捷工具，减少右键操作对其他软件的干扰，并支持多条自定义按键映射。

- **右键工具总开关**：可整体关闭右键快捷操作，恢复原始右键行为。
- **全局排除应用**：默认排除 Blender，可自行增删；移除后不会自动加回。已有手势规则保留。
- **多条全局按键映射**：原始快捷键和目标快捷键均可录制或手动设置，支持说明、独立启停和增删；保留总开关，旧的双击修饰键配置自动迁移。
- **Fn / 🌐 支持**：可将普通键映射为单独 Fn，也可将 Fn 单击/双击作为原始触发。按下与松开配对处理，避免长按重复触发；菜单键不再显示为难以辨认的 Key 110。
- **配置与交互改进**：重复原始快捷键提示冲突，映射输出不会再次触发自身；按键录制在主键松开时完成。映射页沿用右键工具的表格、按钮和权限区样式。

## 安装与更新

已安装版本可从应用菜单中的「检查更新」升级，也可下载 `Codex.Quota-arm64.zip`，解压后覆盖 `/Applications/Codex Quota.app`。

全局按键映射需要「辅助功能」和「输入监听」权限。当前发布面向 Apple Silicon、macOS 13 及以上，使用本地自签名证书，未经 Apple 公证；首次打开若被系统拦截，请从系统设置的「隐私与安全性」处理。请只从本仓库下载。

## 验证范围

263 项项目测试、15 项按键控制器检查和 7 项右键控制器检查通过。安装版已验证 Fn 选项与保存，已有配置迁移及保留已核对。

Fn 映射的事件检查通过，不等同于所有输入法均可启动语音输入。微信输入法语音输入的实体按键启动和结束，以及 Blender 连续右键拖动，仍需在对应软件与设备上验收。
