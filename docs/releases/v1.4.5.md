# Codex Quota 1.4.5 更新公告

本次更新让默认界面更简洁，并完善右键快捷操作与防睡眠体验。

- **新增“显示重置预告”开关**
  在设置中控制重置预告、日历和 Tibo 入口的显隐，默认关闭，选择自动保存。不影响个人额度倒计时、后台同步和通知。
- **预置 7 条右键快捷操作**
  支持打开调度中心、新建标签、关闭窗口或标签、切换前后标签、最小化和删除。新用户默认关闭总开关，可在“便捷工具”中启用；已有用户的规则和开关保留，默认排除 Blender。
- **优化“熄屏继续工作”**
  有任务运行时临时防止休眠，全部任务结束后自动解除保护；中途亮屏仍保留保护。仅在保护期间加快任务检查，减少平时的额外扫描。
- **完善按钮悬浮说明**
  补充手动防睡眠的开启条件、关闭方式，以及节点评分的测试内容和历史对比用途。
