# Codex Quota v1.3.0

全新「右键快捷操作」：按住右键画个方向，就能触发任意快捷键。设置入口合并为「便捷工具」统一窗口，任务面板更清爽：

- 右键手势触发快捷键：按住右键拖出方向后松开，触发匹配的快捷键；支持双段手势组合 8 方向，拐角误判已修复。
- ⚡️ 立即触发：无需松开右键，画到方向即刻生效，可按规则勾选开启。
- 快捷键配置更灵活：除直接录制外，新增手动组合面板，点选修饰键（⌃⌥⇧⌘）+ 按键自由搭配；内置系统动作清单（调度中心、屏幕保护程序、关闭显示器等）一键选用。
- 按应用生效：过滤条件支持通配符与多应用（`|` 分隔），新增「选取应用」按钮，从当前运行的应用中一键选取，自动填入其 Bundle ID。
- 表格显示修复：修复规则表格「启用」列超出可视宽度被裁切的问题；列宽适配滚动条样式，极端情况下可横向滚动。
- 统一「便捷工具」窗口：滚轮反转、全局快捷键、右键快捷操作三个设置入口合并一处，标签改为文字说明，一目了然。
- 面板显示 Codex 客户端线程：多会话并行时一眼看清任务归属。
- 任务面板更聪明：无调度任务时自动隐藏任务区块；历史任务名可从运行日志回退提取；任务时长显示更人性化。
- 修复派单任务显示「僵尸运行中」的问题。

## 安装说明

`v1.1.5` 起支持应用内自动更新：打开菜单面板 → 齿轮 → 检查更新即可升级。也可以从 GitHub 下载 `Codex Quota-arm64.zip` 手动覆盖旧版。

右键快捷操作需要辅助功能权限：首次使用请按面板提示在「系统设置 → 隐私与安全性 → 辅助功能」中授权。

当前发布使用本地自签名证书且未经 Apple 公证。首次打开如果被 macOS 拦截，请先尝试打开一次，再进入“系统设置 → 隐私与安全性”点击“仍要打开”。请只从本仓库下载。
