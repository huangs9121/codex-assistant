2026-09-08；本机开发更新，版本仍为 1.4.0 / 19，未发版或推送。

## 已实现

- 原始快捷键与映射快捷键均可录制或手动设置；支持多条、说明、独立开关、总开关、加减行。
- 原始触发支持普通键/组合键以及左右 Command、Option、Shift、Control 的单击/双击；同一修饰键的单击和双击视为竞争规则，不能同时启用。
- 已启用行的重复原始触发会提示冲突，保留原配置；新建但未设置完整的行不会触发。
- 旧「左 Command 双击 → Control + Command + C」已迁移为第一条，保留原有开启状态；删除全部后不会再次迁移。
- 普通组合键配对转换按下和抬起，支持长按重复；按住期间修改规则仍按原目标释放；关闭或录制时释放待处理按键。
- 生成的按键带有标记，跳过自身映射；转换时清除原始事件的字符缓存，避免按键码已变但输入仍是原字符。
