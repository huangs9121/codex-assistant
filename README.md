# Codex 助手

面向 Codex 日常使用的开源辅助工具合集。这个仓库用于集中维护菜单栏工具、自动化脚本和后续可复用的小型辅助功能。

## 当前工具

### Codex Quota

原生 macOS 工具，应用内使用「趁手」名称，安装包和更新路径保留 Codex Quota。可选菜单栏或灵动岛入口，查看 Codex / Claude 额度与任务，并使用鼠标滚轮反转、右键手势、按键映射和防睡眠功能。

当前正式版为 **1.5.2 / 27**，新增灵动岛显示器选择，修复收起后透明区域悬停误触；完整改动见 [发布说明](docs/releases/v1.5.2.md)。

#### 它解决什么问题

- **查额度太麻烦**：每 15 秒通过本机 Codex 主动查询最新额度，不用打开 Codex、输入 `/status`。
- **同时使用 Codex 和 Claude**：面板可切换来源；双持灵动岛在刘海两侧分别显示两者，点击对应一侧展开。
- **派给 Codex 的任务没处看**：面板直接显示调度任务的运行状态、时长与退出码；Codex 会话按父子关系分组，桌面端和 CLI 创建的共享历史集中查看。
- **鼠标滚轮方向别扭**：内置仅针对鼠标的垂直滚轮反转，与系统「自然滚动」共存，不用再装第三方反转软件。
- **呼出 Codex 不够快**：双击修饰键（支持区分左右 ⌘/⌥/⇧/⌃）即可映射为 Codex「窗口弹出快捷键」，体验对齐 Kimi 客户端。
- **重置后显示旧数据**：重置卡生效后直接读取服务端新额度，不再等待下一次对话写入本地日志。
- **读错额度池**：只使用主 `codex` 周额度池，不会被 Spark 等独立模型额度覆盖。
- **不知道什么时候重置**：菜单栏可显示中文重置倒计时（不足 24 小时显示小时数）；通过 AIHOT 获取全员重置和发重置卡的预告、确认记录，统一显示北京时间，并可打开原始 X 帖子及完整日历。
- **菜单栏空间不够**：电池、数字徽章、分段电池和纯数字四种样式任选，Codex 文字、OpenAI Logo 也可显示或隐藏。

#### 功能

- “设置 → 额度”提供“显示 Codex 重置预告”：默认关闭，控制面板的预告及日历/Tibo 入口显隐，选择持久化；不影响个人倒计时、后台同步或通知，设置中的日历入口仍可用。
- “设置 → 通用”可选菜单栏或灵动岛。菜单栏保留紧凑进度条和底部工具栏；灵动岛使用双圈与任务列表，可选单个或双持、调整左右方位。两种入口均支持 Codex / Claude 切换
- 灵动岛可选择自动、内置显示器或外接屏，立即生效并保存选择；目标断开时暂回可用屏，保留原选择，重连后恢复。悬停仅命中可见岛的轮廓，下方透明区不触发展开
- 每 15 秒通过本机 Codex 查询最新额度；短暂失败保留上次实时读数 3 分钟，持续失败再显示原因并尝试本地快照。实时成功时不扫描备用日志
- Claude 通过经签名校验的官方 Claude Code CLI 读取额度；被选中或在双持灵动岛显示时每 5 分钟刷新，其余每 15 分钟，手动刷新立即执行。失败保留上次成功数据或使用桌面记录，不由本工具直接读写 Claude 令牌
- 会话日志只解析追加内容，未变化的状态不重复刷新界面，减少后台扫描与排版；不降低任务保护期间的结束检测频率
- 调度任务跟踪：显示任务名、运行状态、时长与退出码；单击恢复 Codex 会话，Option+单击仅复制恢复命令；任务行支持「继续」「删除」，可一键清理已完成任务
- Codex 会话总览：按父子关系分组并默认折叠，显示桌面端或 CLI 创建来源；完成会话可从列表清除，重新活跃后自动恢复显示，原会话文件不会删除
- 当前 CLI 进程：单独显示仍在终端中运行且关联会话的 CLI 进程；可定位原终端，避免为同一会话创建重复恢复操作
- Claude 任务区显示桌面 Code 会话和终端会话；点击桌面任务打开对应 Claude 会话，CLI 任务回到原终端，清理已完成只在本工具中隐藏
- 面板齿轮和应用内 ⌘, 打开同一个设置中心；首次引导可跳过，也可从“设置 → 关于 → 查看引导”重看
- 手动合盖防睡眠：从“设置 → 防睡眠”开启，保持到手动关闭或退出应用，重启默认关闭；任务状态不会自动切换此功能。首次使用需要管理员授权，会接管系统全局防睡眠设置。合盖运行时请保持通风。
- “设置 → 防睡眠 → 开始熄屏”在有运行任务时建立临时保护，全部任务结束后释放，亮屏不主动释放；这是独立于手动合盖防睡眠的功能，使用时插电且不要合盖
- 鼠标滚轮垂直反转：仅作用于鼠标，触控板方向不受影响
- 全局快捷键设置：支持多条原始键到目标键的映射，可录制或手动设置、添加说明并独立启停；保留总开关和原有双击修饰键配置，重复触发规则会提示冲突
- 支持单独 Fn / 🌐 作为映射目标，按下和松开配对处理；特定输入法的语音输入是否响应，需在对应软件中实测
- 右键快捷操作：新安装默认关闭，预置 7 条手势（上：调度中心；下：新建标签；下→右：关闭；右/左：下一个/上一个标签；左下：最小化；右上：删除）。默认排除 Blender；已有开关、自定义规则及空规则列表保留
- 根据 macOS 首选语言自动显示简体中文或英文，其他语言回退英文
- 四种显示样式：原生电池、数字徽章、分段电池、纯数字
- 左侧标识支持 `Codex` 文字、OpenAI Logo 或隐藏
- 信息区显示精确到秒的更新时间、下次重置和当前套餐
- 识别到 Codex 真实额度周期已重置后，在首个 15 秒轮询内发送 macOS 系统通知，并按周期去重
- 从 [AIHOT 重置日历 API](https://aihot.news/api/v1/codex-resets) 每 5 分钟条件同步公开记录，区分全员重置与发重置卡、预告与确认；面板只显示尚未确认且未过期的预告及其北京时间、中文摘要，提供原帖、重置日历及 Tibo X 主页入口
- 首次同步静默载入历史，后续新的预告和确认通过 macOS 通知提醒并去重；同步失败保留缓存并显示状态，已确认和已过预计时间的记录不再显示在预告区，历史记录可从“重置日历”查看
- 公开重置记录与个人额度分开：确认帖时间不等于账户实际到账时间，发重置卡不代表额度已恢复；API 不提供群推送或个人重置卡余额
- 支持 GitHub 新版本提醒；确认后自动下载、校验、替换并重启
- 按住 Command（⌘）拖动图标，可调整它在菜单栏中的位置
- 滚轮反转和右键手势需要「辅助功能」权限，全局按键映射另需「输入监听」权限
- 定位终端或在终端恢复任务时，macOS 可能请求控制 Terminal 的「自动化」权限
- 仅支持 arm64（Apple Silicon）和 macOS 13 及以上

开机启动默认关闭；启用前建议先将 App 放入 `/Applications`。

## 安装

同事可从 [GitHub Releases](https://github.com/huangs9121/codex-assistant/releases) 下载 `Codex.Quota-arm64.zip`，解压后将 `Codex Quota.app` 拖入 `/Applications`。首次运行如果被 macOS 拦截，请先尝试打开一次，再进入“系统设置 → 隐私与安全性”点击“仍要打开”。

更新 ZIP 只包含应用；[安装与使用说明](docs/打开说明.txt) 单独提供。

当前发布使用本地自签名证书且未经 Apple 公证，Gatekeeper 出现安全提醒属于预期情况。请只从本仓库下载。

## 更新策略

App 启动和持续运行期间按策略检查 GitHub 公开 Release：成功后至少间隔 24 小时，失败后至少间隔 1 小时重试。检查只向 GitHub 公开 API 发出 `GET` 请求。

也可从“设置 → 关于 → 检查更新”手动检查。发现新版本后，用户点击“立即更新”即可完成整个流程：下载固定的 arm64 ZIP、核对 GitHub 提供的 SHA-256、验证 Bundle ID、版本、签名和 arm64 架构，然后退出旧版、原位替换并自动重启。任一校验或安装步骤失败都会保留旧版本，并提供 GitHub 手动下载入口。App 位于 `/Applications` 且目录不可写时，macOS 会在安装阶段请求管理员授权。

`v1.1.4` 本身尚未包含自动更新器，因此升级到 `v1.1.5` 仍需手动安装一次；此后的版本可以在 App 内完成更新。

## 隐私

- App 通过本机 Codex 和官方 Claude Code CLI 查询额度，不直接读取、复制或保存两者的账号令牌；Claude 的凭据与续期由官方 CLI 管理。
- 为显示任务与会话状态，App 在本机读取 Codex / Claude 会话标题、ID 关系、创建来源、状态、修改时间及关联进程信息；这些本地内容不会上传。
- App 不保存一份对话正文副本。公开重置动态只读获取 AIHOT API，版本检查访问 GitHub 公开 Release。

## 构建

需要 macOS 13 及以上、Apple Silicon 和 Swift 6。从仓库根目录运行：

```bash
apps/codex-quota/Scripts/build_app.sh
```

构建完成后生成：

```text
outputs/Codex Quota.app
outputs/Codex Quota-arm64.zip
```

构建脚本会运行测试并生成自签名的 arm64 App 和 ZIP。

## 重置动态数据来源

重置动态由 AIHOT 整理，属于第三方公开记录，非 OpenAI 官方通知服务。应用仅请求公开 API，不向 AIHOT 发送 Codex 登录信息或个人额度；缓存与 ETag 保存在本机，完整历史及译文通过日历链接查看。使用 AIHOT 服务须遵守其[公开使用规则](https://aihot.news/terms)；本仓库的 MIT 许可证不授予 AIHOT 数据或服务的额外权利。
